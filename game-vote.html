⚙️ Firebase 연결 필요 (1회만 설정)

실시간 데이터 공유를 위해 Firebase 프로젝트 설정값을 입력해주세요.
아래 단계를 따라하면 5분이면 됩니다.

  1. console.firebase.google.com 접속 → 프로젝트 만들기
  2. 프로젝트 이름 입력 → Google Analytics 건너뛰기 → 완료
  3. 왼쪽 메뉴 빌드 → Realtime Database → 데이터베이스 만들기
  4. 테스트 모드로 시작 → 완료
  5. 상단 URL 복사 (예: https://xxx-default-rtdb.firebaseio.com)
  6. 왼쪽 상단 톱니바퀴 → 프로젝트 설정 → 아래 앱 추가(</> 웹) → 설정값 복사

✅ 연결 완료! 이제 링크를 공유하세요.
